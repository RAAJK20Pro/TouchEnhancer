# Touch Enhancer V5

**Release Date:** 2026-10-03  
**Author:** @RAAJK20Pro  
**Supported Root:** Magisk • KSU • APatch  
**Channel:** Kernel Enhancer

## What's New

- SurfaceFlinger tweaks now actually apply at boot.
- Correct refresh rate detection for **60 / 90 / 120 / 144Hz+** displays.
- Max refresh rate can now be unlocked live — **no reboot required**.
- Touch Game Mode support for supported **OPPO / OnePlus / realme / Xiaomi** devices.
- Reduced ~120 boot processes to a small number of essential processes for a faster and lighter boot.
- Added low-priority late-stage execution to prevent lag immediately after boot.
- Built-in watchdog protection to prevent Touch Enhancer from hanging the boot process.
- Signed build support — modified ZIP packages are rejected during installation.
- Cleaner logging with a dedicated log file:
  `/data/local/tmp/TouchEnhancer.log`
