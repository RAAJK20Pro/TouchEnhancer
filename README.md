## Why Use TouchEnhancer?

Stock configurations prioritize balance. TouchEnhancer focuses on improving input response and UI consistency.

- `Improved Responsiveness` — Enhances touch and gesture handling  
- `Reduced Input Delay` — Helps lower perceived touch latency  
- `UI Smoothing` — Maintains more consistent frame timing  
- `Rendering Optimization` — Adjusts display pipeline behavior  
- `Persistent Tweaks` — Applies optimizations at boot

## Installation

1. Download the latest `.zip` from [Releases](https://github.com/RAAJK20Pro/TouchEnhancer/releases)  
2. Open Magisk or KernelSU  
3. Go to Modules → Install from Storage  
4. Select the zip file and reboot
